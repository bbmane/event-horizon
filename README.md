**Never miss a sci-fi or cyberpunk release again.**

Event Horizon is a community-curated calendar of upcoming sci-fi releases — built by fans, for fans, with no ads, no tracking, and no algorithm deciding what you should care about.

🤖 [Explore Event Horizon](https://bbmane.github.io/event-horizon/)

## Why Event Horizon

- **See what's coming, at a glance.** A clean, browsable calendar of everything sci-fi and cyberpunk on the horizon — movies, anime, games, manga, and more.
- **Find exactly your kind of story.** Filter by type and by theme — cyberpunk, dystopian, mecha, space opera, and a dozen more — to surface what you're into, or stumble onto something new.

- **Built by the community, for the community.** Every entry on the calendar was submitted by someone who was excited about it. No submission requires an account, an email, or any personal info at all.

## Add a Release

Spotted something missing? Adding it takes less than a minute:

1. Head to the **[Submit a Release](https://bbmane.github.io/event-horizon/submit.html)** page.
2. Add the title, release date, a source link, and the themes that fit.
3. Once a moderator approves it, it shows up on the calendar automatically.

Have a GitHub account and want to track your own submission? Use the **[Submit a Release](https://github.com/bbmane/event-horizon/issues/new?template=report-release.yml)** issue template instead — same result, but you can follow along and edit it yourself.

Spotted a mistake on something already on the calendar (dead link, wrong date, wrong tags)? Use **[Report a Correction](https://github.com/bbmane/event-horizon/issues/new?template=report-correction.yml)** — this one requires a GitHub account, since a moderator needs to reference your report while fixing the original entry.

Not sure if something counts as a new release, or which date to use for a manga or series? Check the **[Submission Guidelines](https://github.com/bbmane/event-horizon/wiki/Submission-Guidelines)** wiki page first.
